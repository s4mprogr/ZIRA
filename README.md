# Landing — Sitio estático (HTML/CSS/JS puro)

## Subir a GitHub + Vercel

1. Crea un repo nuevo en GitHub y sube estos 4 archivos (`index.html`, `styles.css`, `script.js`, este `README.md`) a la raíz — no dentro de una subcarpeta.
2. Entra a vercel.com → **Add New Project** → importa el repo.
3. Framework Preset: deja **Other** (sitio estático, sin build). Build Command y Output Directory: déjalos vacíos.
4. Deploy. Vercel te da la URL en segundos.
